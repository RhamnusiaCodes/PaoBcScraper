Android

iPhone / iPad

Λεπτομερώς

Οδηγίες βήμα-βήμα

  1. Android / Google Calendar: Πάτα «Προσθήκη σε Google Calendar», επίλεξε τον λογαριασμό σου και πάτα «Προσθήκη ημερολογίου». Θα εμφανιστεί στο app σε λίγα λεπτά.
  2. iPhone / iPad: Άνοιξε το link σε Safari. Αν δεν ανοίξει τίποτα, πήγαινε στα Ρυθμίσεις → Ημερολόγιο → Λογαριασμοί → Προσθήκη λογαριασμού → Άλλος → Προσθήκη ημερολογίου εγγραφής και επικόλλησε το link του iCal.
  3. Mac: Άνοιξε το ίδιο link — το Ημερολόγιο των Apple θα προτείνει αυτόματα εγγραφή.
  4. Οι αγώνες ενημερώνονται αυτόματα καθημερινά. Δεν χρειάζεται καμία χειροκίνητη ενέργεια μετά την πρώτη εγγραφή.
